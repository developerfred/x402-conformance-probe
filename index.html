🔁 Replay Offline

Toda falha é reproduzível a partir dos fixtures salvos. Rode localmente:

npm run fetch && npm run validate && npm run replay
Por que isso importa: um 402 quebrado é invisível até um agente tentar pagar — e então a falha parece ser do comprador. Esta tabela pública transforma o problema em responsabilidade do vendedor, com um recibo.
